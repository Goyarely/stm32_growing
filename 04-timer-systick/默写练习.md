# 第 04 章 · 默写练习（从"看得懂"到"写得出"）

> **核心观念**：没有人对着空文件写驱动代码。
> 工程师写的是**骨架**，参数和 API 名字现场查。
> 本文件的作用：把"骨架"从纸上搬进你的手指。

---

## 一、先背这 6 个骨架

### 骨架 1 · 外设初始化万能 6 步 ⭐ 最重要

```c
void Xxx_Init(void)
{
    /* ① 开时钟 —— 永远是第一步，忘了它后面全白写 */
    __HAL_RCC_XXX_CLK_ENABLE();

    /* ② 选实例（一个外设可能有多个：TIM1~TIM4、USART1~3） */
    s_hxxx.Instance = XXX1;

    /* ③ 填参数（查参考手册算出来） */
    s_hxxx.Init.字段A = ...;
    s_hxxx.Init.字段B = ...;

    /* ④ 交给 HAL —— 这是"把参数包交出去"，不是硬件动作 */
    HAL_XXX_Init(&s_hxxx);

    /* ⑤ 中断类外设才有这一步 */
    HAL_NVIC_SetPriority(XXX_IRQn, 1, 0);
    HAL_NVIC_EnableIRQ(XXX_IRQn);

    /* ⑥ 启动（查询类用 _Start，中断类用 _Start_IT） */
    HAL_XXX_Start_IT(&s_hxxx);
}
```

**记忆口诀：钟 → 例 → 参 → 交 → 中 → 启**（开时钟、选实例、填参数、交给HAL、配中断、启动）

---

### 骨架 2 · 中断向量转发（写在 `stm32f1xx_it.c`）

```c
void XXX_IRQHandler(void)      /* 名字必须和启动文件向量表里一致 */
{
    Yyy_IrqHandler();          /* 一行转发，逻辑不写在这里 */
}
```

> **为什么中间要转一层？** 让 `it.c`（CubeMX 生成的文件，可能被覆盖）保持"随时可被重新生成"，你的代码在 `Yyy.c` 里，安全。

---

### 骨架 3 · ISR 三步：查 → 清 → 做

```c
/* ---------- 手写版（第 09、15 章的位带操作会用到） ---------- */
void Yyy_IrqHandler(void)
{
    if (XXX->SR & XXX_SR_FLAG)          /* ① 查：是我触发的吗 */
    {
        XXX->SR = (uint32_t)~XXX_SR_FLAG;   /* ② 清：不清会无限重入 */
        /* ③ 做：真正的业务 */
    }
}

/* ---------- HAL 版（本章用的） ---------- */
void Yyy_IrqHandler(void)
{
    HAL_XXX_IRQHandler(&s_hxxx);   /* ① ② ③ 它全包了（内部还会调回调） */
}
```

> ⚠️ **两种"清标志"的写法，千万别混**：
> | 外设 | 清除方式 | 写法 |
> |---|---|---|
> | `EXTI->PR` | **写 1** 清除 | `EXTI->PR = pin;` |
> | `TIMx->SR`、`USARTx->SR` | **写 0** 清除 | `TIM2->SR = ~TIM_SR_UIF;` |
>
> **本章的破坏性实验就是故意用错**，看它卡死。

### 骨架 4 · 回调分发

```c
void HAL_XXX_PeriodElapsedCallback(XXX_HandleTypeDef *hxxx)
{
    if (hxxx->Instance == XXX1)
    {
        /* TIM2 的事 */
    }
    else if (hxxx->Instance == XXX2)
    {
        /* TIM3 的事 */
    }
}
```

> **回调是"弱函数"**：HAL 里有一份空实现（`__weak`），你写一份同名的，链接器就用你的覆盖它。
> **全工程只能有一份**，所以多个定时器必须在里面用 `Instance` 分发。

---

### 骨架 5 · 跨中断通信（标志位 + 读走即清）

```c
/* ---------- 写的一方：中断 ---------- */
static volatile uint8_t s_flag[N] = {0};     /* static 锁作用域 + volatile 防优化 */

void Isr(void)
{
    s_flag[i] = 1U;                          /* 只置位，不做别的事 */
}

/* ---------- 读的一方：主循环 ---------- */
uint8_t Take(void)
{
    if (s_flag[i] == 0U)                     /* 先判 */
    {
        return 0U;
    }
    s_flag[i] = 0U;                          /* 再清 —— 漏了这句就变成"一直按着" */
    return 1U;
}
```

**两个词的作用**：

| 关键字 | 防住什么 |
|---|---|
| `static` | 外部看不见 → 不会被重名、不会被误改 |
| `volatile` | 编译器不敢缓存 → 每次真去内存读 → 能看到中断的修改 |

### 骨架 6 · 表格法（引脚/硬件描述）

```c
typedef struct
{
    GPIO_TypeDef *port;
    uint16_t      pin;
    uint32_t      rccMask;
} Hw_t;

static const Hw_t g_hw[] =
{
    { GPIOB, GPIO_PIN_12, RCC_APB2ENR_IOPBEN },

#define HW_NUM   (sizeof(g_hw) / sizeof(g_hw[0]))

/* 用的时候 for 循环遍历 */
for (uint8_t i = 0; i < HW_NUM; i++) { ... g_hw[i].port ... }
```

**好处**：加一个按键只改表格，不动逻辑。

## 二、本章到底要写哪几个函数？（函数清单）

### 通用公式：**每个外设最多 3 个函数**

| # | 函数 | 作用 | 什么时候需要 |
|---|---|---|---|
| 1 | `Xxx_Init()` | 初始化：配置寄存器 | **永远需要** |
| 2 | `Xxx_IrqHandler()` | 中断入口（转发） | 只有用**中断**时才需要 |
| 3 | 回调 / 业务函数 | 真正干活的地方 | 有中断就有回调 |

**用这三个问题判断**：

```
Q1: 这个外设要配置吗？              → 是 → 写 Xxx_Init()
Q2: 它会"自己主动通知我"吗？         → 是 → 写 Xxx_IrqHandler() + 回调
Q3: 它只是被我查询吗？               → 是 → 只写 Xxx_Init() + 读函数
```

- **TIM2**：要配（Q1✓）+ 要主动通知（Q2✓）→ **3 个函数**
- **LED**：要配（Q1✓）+ 不主动通知（Q2✗）→ **2 个函数**（`Led_Init` + `Led_Toggle`）

### ⭐ 名字的"所有权"（你最困惑的地方）

```
硬件产生中断
    │
    ▼
① TIM2_IRQHandler()                ← ❌ 名字【硬件规定】，不能改
    │                                  （启动文件向量表里的名字）
    ▼
② Tim_IrqHandler()                 ← ✅ 名字【你自己起】
    │
    ▼
③ HAL_TIM_IRQHandler(&s_htim2)     ← ❌ 名字【HAL 规定】
    │                                  （它内部：查标志 → 清标志）
    ▼
④ HAL_TIM_PeriodElapsedCallback()  ← ❌ 名字【HAL 规定】
                                       （你必须用这个名字，否则不会被调到）
```

> **看清这张图：整条链路里，只有第 ② 个名字是你自己起的。**
> 其他三个都是"别人定好、你必须抄对"的固定名字。
> **所以你不是在"发明 API"，你是在"填写指定的坑位"。**

| 层 | 名字从哪来 | 写在哪 |
|---|---|---|
| ① 向量表入口 | **启动文件 `startup_stm32f103xb.s`** | `stm32f1xx_it.c` |
| ② 转发层 | **你起**（习惯叫 `Xxx_IrqHandler`） | `Driver/xxx.c` |
| ③ HAL 处理 | **HAL 库**（`stm32f1xx_hal_xxx.c`） | 不用写，只调用 |
| ④ 回调 | **HAL 库**（弱函数） | `Driver/xxx.c`（你重写它） |

### 写的顺序：**从接口 → 实现**（专业习惯）

```
① 先写 tim.h        ← 先想清楚"对外要暴露什么"（2 行）
        ↓
② 再写 tim.c 的空壳  ← 只写函数签名和大括号（5 分钟，不填内容）
        ↓
③ 逐个填肉          ← 按骨架 1 / 3 / 4 填
        ↓
④ 写 it.c 的一行转发
        ↓
⑤ 写 main.c 的两行调用
```

> **"先写空壳"是攻克"空白恐惧"最有效的一招**：
> 把函数签名和大括号先敲出来（这一步不需要动脑），屏幕上就不是空的，
> 然后你面对的**不是"写程序"，而是"填 3 个坑"** ——难度掉一个数量级。

### L2 / L3 完整参考

```c
#include "tim.h"
#include "stm32f1xx_hal.h"
#include "stdint.h"
#include "led.h"

static TIM_HandleTypeDef s_htim2;

/* ==================================================================
 * 初始化：TIM2 每 1ms 产生一次更新中断
 *   72MHz，10kHz 计数频率：PSC = 72e6/10e3 - 1 = 7199
 *   1ms = 10 个计数：      ARR = 10 - 1          = 9
 * ================================================================== */
void Tim_Init(void)
{
    __HAL_RCC_TIM2_CLK_ENABLE();

    s_htim2.Instance = TIM2;
    s_htim2.Init.Prescaler = 7199;
    s_htim2.Init.CounterMode = TIM_COUNTERMODE_UP;
    s_htim2.Init.Period = 9;
    s_htim2.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
    s_htim2.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_DISABLE;

    HAL_TIM_Base_Init(&s_htim2);

    HAL_NVIC_SetPriority(TIM2_IRQn, 1, 0);
    HAL_NVIC_EnableIRQ(TIM2_IRQn);

    HAL_TIM_Base_Start_IT(&s_htim2);
}

/* ISR 主体：由 stm32f1xx_it.c 的 TIM2_IRQHandler() 转发调用 */
void Tim_IrqHandler(void)
{
    HAL_TIM_IRQHandler(&s_htim2);
}

/* HAL 弱回调：全工程唯一的实现，以后所有定时器都在这里分发 */
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    static uint32_t s_cnt1 = 0;
    static uint32_t s_cnt2 = 0;

    if (htim->Instance == TIM2)
    {
        /* LED1：每 500ms 翻转（500 × 1ms） */
        if (++s_cnt1 >= 500U)
        {
            s_cnt1 = 0;
            Led_Toggle(LED_1);
        }

        /* LED2：每 3s 翻转（3000 × 1ms） */
        if (++s_cnt2 >= 3000U)
        {
            s_cnt2 = 0;
            Led_Toggle(LED_2);
        }
    }
}
```

**`stm32f1xx_it.c` 里**：

```c

{
    Tim_IrqHandler();
}
```

### 自测题答案

| 题 | 答案 |
|---|---|
| 1 | 时钟没开时，外设寄存器访问会被硬件**忽略**（写不进、读为 0），后面对它的所有操作全部无效 |
| 2 | **不会**。`Init` 只是填寄存器，必须有 `HAL_TIM_Base_Start_IT()` 才真正让 CNT 开始计数 |
| 3 | **启动文件 `startup_stm32f103xb.s` 里的向量表**。`it.c` 里的函数名必须和向量表一致，否则中断触发时跳到别处 |
| 4 | 因为回调是**全工程唯一**的一个。多个定时器全进这里，只能靠 `Instance` 区分是谁 |
| 5 | ① 查 `SR` 里的 UIF ② 清 UIF ③ 调 `HAL_TIM_PeriodElapsedCallback()` |
| 6 | **无限重入**：退出 ISR 时 UIF 还是 1 → NVIC 立刻再进来 → CPU 一直在 ISR 里，主循环完全饿死 |
| 7 | 中断里改写它，主循环读它。不加 `volatile`，编译器可能把读取**优化成一次**，主循环永远看不到变化 |
| 8 | `HAL_Delay()` 靠 **SysTick** 计数，而 SysTick 优先级（15）**低于**所有外设中断。在 ISR 里调它会**死等一个永远不涨的计数器** → 卡死 |
